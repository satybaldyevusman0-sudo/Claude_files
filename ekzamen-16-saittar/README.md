## 🚀 Vercel
- **Баарын бир жолу:** ушул папканы GitHub'га жүктөп, Vercel'де *Import Project* кылыңыз. Сайттар `https://сиздин-долбоор.vercel.app/01-kinotime/` сыяктуу дарекке чыгат.
